# My Programming Journey

Личный репозиторий для последовательного 12-недельного изучения Python.

## Как заниматься

Для каждой недели используй один и тот же порядок:

1. Прочитай `notes.md` и перепиши основные идеи своими словами.
2. Запусти и измени примеры из `examples.py`.
3. Реши задания из папки `exercises/` самостоятельно.
4. Проверь решения, запиши ошибки и сделай небольшой Git-коммит.

Сначала пытайся решить задачу сам. Если застрял, сформулируй проблему и используй подсказку, а не копируй готовое решение.
