# Week 1 — Conditions and Boolean Logic

## Цели недели

- Понимать, как программа принимает решения.
- Уверенно использовать `if`, `elif` и `else`.
- Составлять условия с операторами сравнения.
- Комбинировать условия через `and`, `or` и `not`.
- Проверять крайние случаи и объяснять результат каждой ветви.

## Основной синтаксис

```python
if condition:
    # выполняется, если condition равно True
    pass
elif another_condition:
    pass
else:
    pass
```

После условия обязательно ставится двоеточие, а тело блока выделяется отступом.

## Операторы сравнения

| Оператор | Значение |
| --- | --- |
| `==` | равно |
| `!=` | не равно |
| `>` | больше |
| `<` | меньше |
| `>=` | больше или равно |
| `<=` | меньше или равно |

Важно: `=` присваивает значение, а `==` сравнивает значения.

## Логические операторы

- `and` — оба условия должны быть истинными.
- `or` — истинным должно быть хотя бы одно условие.
- `not` — меняет `True` на `False` и наоборот.

Складывай сложные условия по частям. Если выражение трудно прочитать, используй скобки и временные переменные с понятными именами.
