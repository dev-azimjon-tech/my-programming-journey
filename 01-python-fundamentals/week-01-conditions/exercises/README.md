# Week 1 Exercises

Решай задания по порядку и не смотри готовые решения до собственной попытки.

1. `01_even_odd.py` — определить, является ли число чётным или нечётным.
2. `02_positive_negative.py` — определить, положительное число, отрицательное или ноль.
3. `03_largest_number.py` — найти наибольшее из трёх чисел.
4. `04_grade_calculator.py` — перевести результат теста в оценочную категорию.

Для каждого задания проверь обычный случай, граничное значение и неожиданный/сложный случай.
